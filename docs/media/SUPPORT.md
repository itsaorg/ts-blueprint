# Support

## How to get help

1. Search existing [issues](https://github.com/itsaorg/ts-blueprint/issues) and discussions for the same question.
2. For defects, features, or chores, open an issue with the matching form under **New issue**.
3. For security or conduct reports, do **not** open a public issue — follow [SECURITY.md](SECURITY.md).

## What maintainers cover

- Questions about using this repository as a GitHub template
- Bugs in the published package or the toolchain under `.devenv/`
- Clarifications to CONTRIBUTING and HOW-TO

## What maintainers do not cover

- Custom product logic you add after renaming the template
- Third-party tools outside the documented toolchain
- Private consulting or SLA response times

There is no paid support channel for this repository.
